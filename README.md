# ⚡ JJK AR Experience

An interactive anime-inspired AR experience built using **JavaScript, MediaPipe Hand Tracking, Canvas API, HTML, and CSS**.

This project allows users to activate different cursed techniques using hand gestures detected through their webcam.

## 🎥 Features

- ✋ Real-time Hand Detection
- 🔴 Cursed Technique: RED
- 🔵 Domain Expansion: Unlimited Void
- 🩸 Domain Expansion: Malevolent Shrine
- ⚔️ Animated Cutting Slash Effects
- ✨ Particle Effects
- 🌌 Energy Rings and Visual Effects
- 📷 Live Camera Preview
- 🖐️ Hand Skeleton Visualization
- ⌨️ Keyboard Controls
- 📱 Responsive UI

---

## 🌀 Techniques

### 🔴 Cursed Technique: RED

Activate a powerful red cursed energy effect with expanding particles and energy rings.

**Gesture:** 🤏 Pinch Gesture  
**Keyboard:** `1`

---

### 🔵 Unlimited Void

Activates a domain-inspired visual effect with a massive particle field and energy rings.

**Gesture:** ✋ Open Palm  
**Keyboard:** `2`

---

### 🩸 Malevolent Shrine

Activates a red cursed-energy environment with continuous anime-inspired cutting slash effects.

**Gesture:** ✌️ Two Finger Gesture  
**Keyboard:** `3`

---

## 🎮 Controls

| Action | Control |
|--------|---------|
